# Contributing

Use Node 26.12.1 and pnpm 10.20.0. Run `pnpm install --frozen-lockfile`, `pnpm lint`, `pnpm typecheck`, `pnpm test`, and `pnpm build` before opening a pull request. Regenerate API types after changing the pinned contract. Keep browser checks on demand against a fresh backend stack.
