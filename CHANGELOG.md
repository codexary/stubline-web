# Changelog

## 1.1.0 — 2026-10-30

Adds the browser-only hosted demo, sample ticket and GitHub Pages deployment workflow. Demo reservations now remove a seat from availability, generated order IDs do not overwrite the seeded order, and payment keys reject changed requests.

## 1.0.0 — 2026-10-27

First buyer site for Stubline 1.1.0: event and seat browsing, PKCE sign-in, reservation and order lookup, idempotent payment, ticket download, accessibility, container deployment and CI.
